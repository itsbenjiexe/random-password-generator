# Random Password Generator

A beginner Python program that generators passwords based on user-selected character types and password length.

## Features

- Generates one or more random passwords
- Allows users to choose password length
- Allows users to select included character types:
  - Uppercase letters (A-Z)
  - Lowercase letters (a-z)
  - Numbers (0-9)
  - Special characters
- Handles invalid user input
- Uses functions to organize program logic

## How to Run

1. Clone the repository:
   
```bash
git clone https://github.com/itsbenjiexe/random-password-generator.git
```
2. Navigate to the project folder:

```bash
cd random-password-generator
```
3. Run the program:

```bash
python main.py
```
